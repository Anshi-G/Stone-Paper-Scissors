# 🎮 Stone Paper Scissors Game

A fun and interactive Stone Paper Scissors game built using HTML, CSS, and JavaScript.

## 🚀 Live Demo

🔗 [Click here](https://anshi-g.github.io/Stone-Paper-Scissors/)

## 📌 Features

- User vs Computer gameplay
- Instant result display
- Simple and clean UI

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript

## ▶️ How to Play

1. Choose Stone, Paper, or Scissors
2. Computer will generate a random choice
3. Winner will be displayed instantly
